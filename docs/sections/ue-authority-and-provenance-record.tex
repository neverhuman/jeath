\section{Verification Boundaries and Reproducibility Summary}\label{app:repro}

\subsection{Trusted Computing Base and Verification Scope}

Table~\ref{tab:upgrade} (\S\ref{sec:gaps}) and Table~\ref{tab:v2core} (\S\ref{sec:core}) distinguish formally verified obligations from empirically tested system components. The Verus proofs establish the six properties listed in Section~\ref{sec:core} for the verified kernel functions: conservation and post-fence exclusion, the canonical permit encoding, \(d\)-hop capability attenuation, relational exclusion, the monotone policy ratchet, and skew-buffered quorum quiescence. They do not establish full functional correctness of the broker and sink, whose decision logic, RPC handling and storage are unverified (\VTwoProofs{} verified obligations; \VFiveProofMutationsRejected/\VFiveProofMutationsRejected{} soundness mutations rejected).

Components outside the Verus specification belong to the empirical trusted computing base: the Linux kernel enforcing namespaces, Landlock~v4, and seccomp-BPF; the C SQLite engine executing write-ahead-logged transactions (\texttt{FULL} synchronous durability for the broker and sink of the experiments, \texttt{NORMAL} for the three-process cluster test); physical monotonic clock drift bounded by Assumption~1 (\(|t_{\mathrm{shard}} - t_{\mathrm{broker}}| \le \delta_{\max}\)); out-of-band human custody of Ed25519 steward root keys; and any proxy that wraps an external API to enforce a fence for it (Section~\ref{sec:v6boundary}). A vulnerability or misconfiguration in any of those lower layers can bypass kernel-level invariants without invalidating the SMT theorems.

\subsection{Deterministic Artifact Reproduction}

Every number, table and figure in this PDF is generated from committed reference artefacts without manual number entry, and the build checks that the generated files match those artefacts byte for byte. The validators recompute each reported number from raw artefacts; they are replay checks that share code with the harnesses, not independent implementations (Section~\ref{sec:v6limits}).
