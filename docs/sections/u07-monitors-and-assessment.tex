\section{Context-Isolated Monitors and Stateful Escrow Triage}\label{sec:monitors}

Not every domain invariant reduces to a numeric budget or static path allowlist; ambiguous actions sometimes require semantic inspection before commit. Equation~\eqref{eq:reach} predicts that stacking multiple monitors on a \emph{shared untrusted conversation transcript} suffers severe common-cause coupling (\(c > 0\)), whereas stripping untrusted prose into isolated step-capability schemas restores conditional independence across steps.

The injections are ones this repository rendered into AgentDojo trajectories, the classifiers are small statistical
models calibrated at a fixed per-step false-positive rate, and the isolated-step invariants are not compared at a
matched benign false-block rate; the comparisons below are therefore exploratory.

Table~\ref{tab:v4trajmonitors} tests this prediction across two complementary settings on held-out 5-step AgentDojo v1.2.2 trajectories (\VFourTrajEvalCount{} trajectories; \VFourTrajToolCalls{} live tool executions):
\begin{enumerate}
  \item \textbf{Classifier diversity on shared transcripts stalls past \(k^\star = 2\).} Diversifying five distinct statistical classifier families across a shared conversation transcript still inflates 5-step joint miss \(\VFourTrajHetInflation\times\) above the marginal product \(\prod_{s=1}^5 \hat{m}_s\) (\(\hat{J}_5 = \VFourTrajHetFiveMissPct\%\)), improving by only \(\VFourTrajHetPostKStarFactor\times\) from step~2 to step~5 because injected rationalizations persist across the shared context window.
  \item \textbf{Live Qwen3 LLM-as-judge coupling confirms transcript vulnerability.} Replacing lexical classifiers with live Qwen3-4B and Qwen3-8B language-model judges exhibits the exact same structural split. When judging full untrusted transcripts, multi-step misses remain strongly coupled (\(\VEightLlmJudgeFourBSharedInflation\times\) inflation on Qwen3-4B, \(\hat{J}_5 = \VEightLlmJudgeFourBSharedMissPct\%\); \(\VEightLlmJudgeEightBSharedInflation\times\) on Qwen3-8B, \(\hat{J}_5 = \VEightLlmJudgeEightBSharedMissPct\%\)). Stripping untrusted assistant and tool prose so the LLM judge inspects only structured \texttt{(tool, args, resource, delta)} step records cuts 5-step joint miss to \(\VEightLlmJudgeFourBIsoMissPct\%\) (4B) and \(\VEightLlmJudgeEightBIsoMissPct\%\) (8B).
  \item \textbf{Two-stage reservation escrow eliminates the false-block tax.} Enforcing strict single-stage step invariants rejects \(\VFourTrajIsoFalseBlockPct\%\) of benign 5-step episodes. Routing anomalous step intents into a stateful broker reservation escrow---which holds side effects in staging while verifying cross-step provenance---executes \(\VFourTrajEscrowFastPathPct\%\) of benign tool calls unpaused on the deterministic fast path and reduces episode false aborts \(\VFourTrajEscrowReductionFactor\times\) to \(\VFourTrajEscrowFalseBlockPct\%\) (\(\hat{J}_5 = \VFourTrajEscrowFiveMissPct\%\)).
\end{enumerate}

Controlled 20-dimensional six-family classifier benchmarks, exact Gaussian copula quadrature, and multi-domain generalizability ceilings~\cite{cronbach} further corroborating these coupling laws are detailed in Appendix~\ref{app:sim} (Table~\ref{tab:v3monitors} and Figure~\ref{fig:v3monitors}).
