\section{Mechanized Kernel, Clock-Skew Bounds, and Sink Fencing}\label{sec:core}

\subsection{Mechanized Authority Kernel and Mutation Controls}

To eliminate parser differentials and state-machine bugs inside the reference monitor itself, we implement the core authority transition logic in Rust and verify it with the Verus SMT prover~\cite{verus}. The verified core comprises \VTwoExecFns{} executable functions and \VTwoTheorems{} proofs discharging \VTwoProofs{} verification obligations with \VTwoTriggerWarnings{} solver trigger warnings (Table~\ref{tab:v2core}). Five properties hold over all syntactically representable inputs:
\begin{enumerate}
  \item \textbf{Canonical wire bijection.} Fixed-width 21-byte capability frames satisfy round-trip encoding/decoding bijection and deterministic rejection of non-canonical tags, preventing parser mismatch between broker and sink.
  \item \textbf{Multi-hop delegation attenuation.} Across any \(d\)-hop sub-agent chain, child capability scope is bitmask-monotone and spend limits satisfy \(B_d \le B_{d-1} \le \dots \le B_0\), blocking parallel smurfing across sub-agents (Table~\ref{tab:v9smurfing}).
  \item \textbf{Relational mutex exclusion.} Conflicting resource-pair actions (for example, simultaneous credential read and outbound network dispatch) cannot co-commit within an epoch.
  \item \textbf{Monotone bootstrap ratchet (\textbf{C5}).} Policy version transitions \(P_v \to P_{v+1}\) are rejected unless \(\Permits(P_{v+1}) \subseteq \Permits(P_v)\) or an out-of-band human steward quorum signs the expansion (Figure~\ref{fig:v5scaling}a).
  \item \textbf{Clock-skew-buffered quorum quiescence (\textbf{C3}).} Revocation acknowledgment requires every sink shard either to sign an epoch bump \(e' > e\) or to pass its physical lease-expiry horizon adjusted for bounded clock skew, guaranteeing post-acknowledgment interruption regardless of agent preferences (Figure~\ref{fig:v5scaling}b).
\end{enumerate}

Because formal proofs fail silently if specifications are vacuous, we pair the Verus proof with three negative-control layers. First, \VFiveProofMutationsRejected/\VFiveProofMutationsRejected{} injected soundness mutations---weakening budget conservation, replay tracking, version comparison, delegation attenuation, bootstrap subset checks, or the clock-skew buffer---are each rejected by Verus. Second, exhaustive finite-state exploration over \CheckedStates{} reachable states (\CheckedEdges{} transitions) confirms zero invariant violations under the complete enforcer, whereas omitting the budget clause from the specification admits \OmittedStates{} states and spends \(8\) units against a \(2\)-unit cap. Third, searching \VTwoTraces{} traces across all \VTwoAblationSets{} single and paired protocol-clause omissions yields concrete violation witnesses in every ablated configuration.

\subsection{Bounded Clock Skew and Five-Class Partition Tests}

In a distributed deployment, a network partition can isolate a sink shard before a signed revocation reaches it. Relying on lease expiry to stand in for a missing shard acknowledgment requires an explicit physical timing assumption:

\para{Assumption 1 (Bounded physical clock skew).} At every protocol step, each cooperative sink shard's local monotonic clock \(t_{\mathrm{shard}}\) and the broker's reference clock \(t_{\mathrm{broker}}\) satisfy \(|t_{\mathrm{shard}} - t_{\mathrm{broker}}| \le \delta_{\max}\) for a known hardware/NTP bound \(\delta_{\max} \ge 0\).

If a permit issued at broker time \(t_{\mathrm{issue}}\) carries lease duration \(L_m\), the shard rejects the permit once \(t_{\mathrm{shard}} > t_{\mathrm{issue}} + L_m\). Under Assumption~1, waiting until \(t_{\mathrm{broker}} > t_{\mathrm{issue}} + L_m + \delta_{\max}\) guarantees \(t_{\mathrm{shard}} > t_{\mathrm{issue}} + L_m\) even on a partitioned shard whose clock lags by \(\delta_{\max}\). Both the Verus theorem and mutant~\#10 mechanize this exact inequality: omitting \(\delta_{\max}\) fails verification.

We test this boundary empirically across a three-sink Unix-socket fault-injection cluster (\VFourJepsenSchedulesPerClass{} adversarial partition, packet-drop, delay, and man-in-the-middle schedules per class; Table~\ref{tab:v2core} and Figure~\ref{fig:v5hero}a):
\begin{itemize}
  \item \textbf{Cooperative signed + \(\delta_{\max}\)-buffered fences:} \(0/\VFourJepsenSchedulesPerClass\) post-acknowledgment leaks across both zero-skew schedules (\VFourJepsenCoopSignedFences{} signed quorum fences, \VFourJepsenCoopLeaseExpiries{} lease expiries, \VFourJepsenMitmRejected{} forged acknowledgments rejected) and schedules injecting up to \(45\)\,ms shard clock lag under a \(\delta_{\max} = 50\)\,ms buffer (\(\VEightJepsenSkewBufLeaks/\VFourJepsenSchedulesPerClass\) leaks).
  \item \textbf{Unbuffered clock skew (\(\delta_{\max}\) omitted):} When shard clocks lag by up to \(45\)\,ms and the broker declares quiescence at \(t_{\mathrm{issue}} + L_m\), \(\VEightJepsenSkewUnbufLeaks/\VFourJepsenSchedulesPerClass\) schedules (\(\VEightJepsenSkewUnbufLeakPct\%\)) suffer late commits after revocation acknowledgment.
  \item \textbf{Broker-only revocation (\emph{Stop~2}) and uncooperative sinks:} Returning revocation acknowledgment at the broker while queued requests remain in flight yields \(\VFourJepsenBrokerOnlyLeaks/\VFourJepsenSchedulesPerClass\) (\(\VFourJepsenBrokerOnlyLeakPct\%\)) post-acknowledgment commits; dispatching to an external sink that ignores epoch preconditions yields \(\VFourJepsenUncoopLeaks/\VFourJepsenSchedulesPerClass\) (\(\VFourJepsenUncoopLeakPct\%\)) leaks.
\end{itemize}

\subsection{Cryptographic Hardening, Crash Recovery, and OS Confinement}

Our zero-dependency Ed25519 and HMAC-chained Macaroon verifier enforces canonical scalar bounds (\(S < \ell\)), canonical field encoding, and explicit torsion rejection (\([8]P = \mathcal{O}\)) on both public keys and nonce points. It passes RFC~8032 test vectors, bidirectional OpenSSL~3.0 CLI signature cross-checks, and \VFourCryptoAttacks{} adversarial forgery/malleability trials with \VFourCryptoFalseAccepts{} false accepts. Finally, Linux Landlock~v4 filesystem/network rules~\cite{landlock} and seccomp filters~\cite{seccomp} block all \VTwoProbes/\VTwoProbes{} direct socket, IPC, and resource-limit bypass probes so local user-space code must traverse the broker socket.
