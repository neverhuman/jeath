\section{Introduction}\label{sec:intro}

Agents built on language models now issue payments, edit repositories and change cloud resources through tools. Most
of the safety case for such systems rests on the model: training shapes what it proposes, and a monitor, often another
model, reads what it proposes before a tool runs~\cite{control,metraudit}. Both act on proposals. The harm, however, is
in effects, and an effect is authorized or not by state that a proposal need not show: whether this payment was already
made, whether the person who granted the budget has withdrawn it, whether the record has changed since the agent read
it. This paper separates the two. \emph{Intelligence} lives in proposals: the capacity to search for, predict and
choose actions. \emph{Authority} lives in state: which effects a sink will commit, given what has already been
committed and granted.

The separation is easiest to see when an operator stops an agent, by hand or through a system that tracks and stops
model workloads~\cite{controlroom}. The stop can act in three places (Figure~\ref{fig:v6hero}a). \emph{Halting inference} ends the
stream of new proposals. \emph{Revoking admission} at a broker refuses permits for proposals that arrive later.
\emph{Fencing the sink} raises an epoch floor at the component that writes durable state, so that an operation carrying
an older epoch is refused when it tries to commit, even if it was admitted and dispatched before the stop. Only the
third reaches work already in flight. It is the fencing-token argument of distributed locking~\cite{kleppmann2016}
applied to an agent's authority, and it moves the stop from the producer of proposals to the place where effects
happen.

Moving authority out of the model raises an obvious objection: the gate is then only as good as what it was told to
check. We take that objection as the paper's subject rather than its limitation. The contributions, each with the
evidence behind it:
\begin{enumerate}
  \item \textbf{Stopping a model is not stopping its effects} (measured; Section~\ref{sec:v6stop}). On real broker and
        sink processes under a predeclared grid of tool latencies, concurrency and enforcement delays, we count the
        effects that commit after each kind of stop and the legitimate work each discards, including kills of the
        sink inside its own requests.
  \item \textbf{Without reasoning, reviewers miss violations that live in state} (measured; Section~\ref{sec:v6reviewers}). Shown
        the rules and the state the gate reads, a same-model reviewer that replied with a bare verdict accepted a
        proposal from the approved list that the state had since made unauthorized, in every state-dependent case; on the larger checkpoint
        it accepted none of the altered ones. Reasoning at length closed the gap on the larger checkpoint, at about a hundred
        times the generated tokens per check. A gate checks at commit rather than on a snapshot taken before.
  \item \textbf{Mediation moves the failure into a written specification} (a hypothesis, illustrated by
        construction and measured on a public benchmark; Sections~\ref{sec:v6reviewers} and~\ref{sec:v6cost}). A gate
        missing one clause admits exactly the violations of that clause. On AgentDojo, with grants written without the
        benchmark's reference solutions, we measure what a specification costs in benign utility, against an
        unprotected agent and a per-call policy, and what it leaves open to injections written to stay inside it.
  \item \textbf{Which real effect surfaces can be fenced} (measured on CPU fixtures; Section~\ref{sec:v6boundary}).
        Executable probes against PostgreSQL, etcd and a POSIX filesystem sort each mechanism by who enforces the
        epoch: the surface itself, author code installed in it, or a condition the writer must remember to send.
  \item \textbf{A predeclared replication at the planned size} (predeclared; Section~\ref{sec:v6replication}). The
        previous version's\footnote{An unpublished earlier draft of this paper. Its code and evidence are in the same repository
        (\texttt{evidence/v2}, \texttt{evidence/v3}), and its experiments are reproduced, with corrections, in the
        appendices.} five-controller comparison could not clear its own noninferiority margin even with no losses.
        We rerun it at the sample size its design diagnostic gives, with the frozen analysis, and report the result
        whatever it is: \vsixEOneHeld{} component claims held. At that size a single lost case defeats a usefulness
        claim, so this is a strict test of the previous version's claims rather than new evidence for the thesis.
  \item \textbf{A machine-checked authority kernel} (proved; Section~\ref{sec:core}), with the gap between the
        verified functions and the code the experiments run stated explicitly.
\end{enumerate}

\para{What this paper does not show.} All live results use quantized open-weight models on CPU, decoding greedily except where E5 samples
proposals; none uses a frontier model. There is no end-to-end control evaluation in which an adaptive red team attacks the whole
system, which is the evaluation that would test these components together. The sink mediates only its own database effects; it does not provide external exactly-once
execution, and an external surface is fenced only if it can refuse a stale epoch. The guarantees hold at a fixed grant.
If more capable or more agreeable agents are granted more, intelligence regains reach through what people
confer (Observation~\ref{obs:conferral}); we state a design for measuring that but have not run it.

\para{Roadmap.} Section~\ref{sec:gaps} sorts safety evidence by whether it survives a model upgrade and places the work
among prior systems. Section~\ref{sec:core} gives the kernel and protocol. Sections~\ref{sec:v6stop}
to~\ref{sec:v6boundary} report the experiments, Section~\ref{sec:v6limits} the limits, and Section~\ref{sec:conclusion}
concludes. The formal reach model and the previous version's experiments are in the appendices, with the corrections
this version makes to them.
