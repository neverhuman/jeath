\subsection{Deterministic Runtime, Numerical Primitives, and Scope}
All synthetic and scaling experiments execute deterministically on CPU from master seed $20261110$ with fixed domain-separation Weyl offsets per module, paired with a standalone $64$-bit pseudorandom bijection, a $128$-layer Marsaglia--Tsang Ziggurat normal sampler, Cody rational complementary error function approximation, Acklam--Halley normal quantile inversion, and a $200$-node Golub--Welsch symmetric tridiagonal QL quadrature solver~\cite{golub}.

Two methodological boundaries apply across all Tier-4 synthetic models. First, every classifier, graph solver, statistical certificate, and evolutionary or policy-gradient loop is implemented from scratch in standalone Rust with zero third-party machine-learning crates; the synthetic monitor suite is therefore an independent boundary testbed rather than a frontier language-model correlation measurement. Second, elementary floating-point transcendentals call the standard platform C math library on Linux x86-64 with cryptographic digest verification across all generated summaries, without claiming unmeasured cross-architecture bit-identity.
