\subsection{Synthetic Directed Acyclic Graph Interdiction}

To isolate graph waist width \(w\) while holding path multiplicity roughly constant (\(\VThreeInterNarrowPathsM\)M--\(\VThreeInterWidePathsM\)M source-to-sink pathways across 8-stage sparse DAGs, \VThreeInterGraphsPerFamily{} graphs per family), Figure~\ref{fig:v3interdiction} compares Dinic minimum-cut interdiction~\cite{dinic1970} computed on Boltzmann-sampled red-team path reports against patching specific reported nodes. On narrow-waist graphs (\(w = \VThreeInterNarrowWidth\)), \(N = 300\) path reports suffice for minimum-cut gating at budget \(B = 6\) to block \(\VThreeInterNarrowCutSixBlockedPct\%\) of pathways and completely sever \(\VThreeInterNarrowCutSixSeverPct\%\) of graphs (\(\VThreeInterNarrowSeverThreeThousandPct\%\) at \(N = 3{,}000\)), whereas patching \(B = 32\) specific nodes severs \(\VThreeInterNarrowPatchThirtyTwoSeverPct\%\). On wide graphs (\(w = \VThreeInterWideWidth\)), even \(N = 3{,}000\) reports sever only \(\VThreeInterWideSeverThreeThousandPct\%\) at \(B = 6\); on these synthetic graphs, report-driven severing needs a narrow waist. Across \VThreeCutsBruteForceChecked{} small random DAGs, weighted vertex-splitting Dinic cuts match brute-force optimal subsets with \VThreeCutsBruteForceDiscrepancies{} discrepancies.

\subsection{20D Six-Family Classifiers, Copula Quadrature, and Portfolio Ceilings}

Table~\ref{tab:v3monitors} and Figure~\ref{fig:v3monitors} evaluate monitor failure correlation and multi-domain assessment ceilings:
\begin{itemize}
  \item \textbf{Gaussian copula quadrature.} Using 200-node Golub--Welsch Gauss--Hermite quadrature~\cite{golub} at single-monitor miss \(m = 0.10\) (Figure~\ref{fig:v3monitors}a), equicorrelation \(\rho = 0.6\) inflates 6-monitor joint miss \(\VThreeCopulaRhoSixInflation\times\) over \(m^6\) (\(\VThreeCopulaRhoSixSixPct\%\) vs.\ \(\VThreeCopulaIndepSixPct\%\)).
  \item \textbf{Six-family 20D classifier suite.} Across \VThreeMonTasks{} synthetic teacher seeds (\(5\%\) benign false-positive calibration across multilayer perceptron, random Fourier quadratic, stump ensemble, nearest-neighbor, radial-basis, and logistic classifiers; Table~\ref{tab:v3monitors} and Figure~\ref{fig:v3monitors}b), architectural diversity on a \emph{shared} step input still suffers \(\VThreeMonSameHetPassiveRatio\times\) passive (\(\rho_{\mathrm{adv}} = 0\)) and \(\VThreeMonSameHetAdvRatio\times\) adversarial (\(\rho_{\mathrm{adv}} = 2.0\)) inflation at \(k = 6\), whereas evaluating distinct step inputs tracks the independent product at the cost of \(\VThreeMonFalseBlockSixPct\%\) single-stage benign false blocks.
  \item \textbf{Multi-domain generalizability ceiling.} Under crossed random-effects generalizability theory~\cite{cronbach} (\VThreeVarSubjects{} subjects; Figure~\ref{fig:v3monitors}c), repeating a single benchmark \(64\) times stalls at \(R_G^2 = \VThreeVarRepeatSixtyFourPct\%\) (single-domain ceiling \(\VThreeVarSingleDomainCeilingPct\%\)), whereas \(64\) diverse domains reach \(\VThreeVarDiverseSixtyFourPct\%\) below the shared-bias ceiling \(\VThreeVarSharedCeilingPct\%\). Similarly, scaling evaluator panel size to \(M = 64\) on a single context \(C_{\mathrm{ctx}} = 1\) stalls at \(\VThreeVarPanelSixtyFourContextOnePct\%\), whereas \(M = 4\) across \(C_{\mathrm{ctx}} = 64\) contexts reaches \(\VThreeVarPanelFourContextSixtyFourPct\%\).
\end{itemize}
