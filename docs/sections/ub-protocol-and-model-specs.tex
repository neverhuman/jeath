\section{Protocol, Wire, and Confinement Specifications}\label{app:specs}

\subsection{Canonical Wire Frame and Attenuated Credentials}

The broker and sink compare a submitted permit with the approved one through a canonical byte encoding: a version tag, then each field in a fixed order as a 64-bit little-endian field tag followed either by a 64-bit value (effect kind, amount, expiry, expected revision) or by a 64-bit length and that many bytes or items (identifier, actor, target, contents, per-issuer epochs, required issuers). Verus proves that the decoder accepts a byte string exactly when it is the encoding of some permit whose fields fit in 64 bits, and then returns that permit, so two permits are equal exactly when their encodings are, and no byte string decodes two ways. Between processes, permits travel as JSON lines, parsed with unknown fields rejected; that parsing is not verified.

Multi-agent delegation wraps this frame in an HMAC-SHA256 Macaroon chain~\cite{birgisson2014} anchored at the broker's epoch root key. Each delegation hop appends a caveat \((\mathrm{mask}_h, \mathrm{cap}_h, \mathrm{exp}_h)\); the sink verifier folds the caveat chain deterministically and accepts only when effective scope is the bitwise intersection \(\bigcap_{h=0}^d \mathrm{mask}_h\), cumulative hop spend never exceeds \(\min_{0 \le h \le d} \mathrm{cap}_h\), and \(t_{\mathrm{shard}} \le \min_{0 \le h \le d} \mathrm{exp}_h\).

\subsection{Clock-Skew-Buffered Quorum Fencing}

During an authority withdrawal from epoch \(e\) to \(e' > e\) across \(S\) cooperative sink shards, shard \(j\) is verified quiescent once either:
\begin{enumerate}
  \item shard \(j\) persists \(e^{\mathrm{floor}}_j \leftarrow \max(e^{\mathrm{floor}}_j, e')\) in write-ahead-logged storage and returns an Ed25519 signature over \((j, e')\) verified against its pinned public key; or
  \item no signed acknowledgment arrives across a partition, and the broker's reference clock passes \(t_{\mathrm{broker}} > t_{\mathrm{issue}}^{\max}(j, e) + L_m + \delta_{\max}\), where \(t_{\mathrm{issue}}^{\max}(j, e)\) is the latest timestamp at which any epoch-\(e\) lease was issued for shard \(j\).
\end{enumerate}
Under Assumption~1 (\(|t_{\mathrm{shard}} - t_{\mathrm{broker}}| \le \delta_{\max}\)), condition~(2) implies \(t_{\mathrm{shard}} > t_{\mathrm{issue}}^{\max}(j, e) + L_m\), so any delayed epoch-\(e\) request arriving at shard \(j\) after broker acknowledgment fails the shard's local lease check.

\subsection{Linux OS Confinement Profile}

To prevent local user-space agent code from bypassing the broker (\(u > 0\)), the confinement wrapper applies three kernel mechanisms prior to executing untrusted tool code: (i)~unprivileged user and network namespace isolation; (ii)~Landlock~v4 filesystem and TCP rules restricting path access to designated workspace scratch directories and permitting socket connections solely to the broker's Unix-domain descriptor; and (iii)~a seccomp-BPF filter blocking raw socket creation, cross-process debugging, System~V and POSIX shared-memory attachment, and resource-limit escalation (\VTwoProbes/\VTwoProbes{} bypass probes blocked).
