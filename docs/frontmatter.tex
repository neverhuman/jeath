\textbf{Abstract.}\enspace
Scaling a model's reasoning or candidate search neither confers authority to mutate external state nor keeps classifier-based safety gates reliable. Stopping an autonomous agent involves three distinct events---halting token generation, revoking admission at a broker, and fencing the state-bearing sink---and only the third stops operations already in flight. Rather than inferring model intent, we enforce \emph{conferred, revocable authority} at cooperative capability-bearing sinks via canonical wire bijections, clock-skew-buffered quorum epoch fences, attenuated delegation credentials, and monotone spend ledgers (\VTwoProofs{} verified Verus obligations over all proposer inputs). Across asynchronous network partitions, broker-only revocation permits \VFourJepsenBrokerOnlyLeaks/\VFourJepsenSchedulesPerClass{} late commits after withdrawal acknowledgment, whereas cooperative sink fencing permits $0$ while increasing safe-and-useful task completion across live open-weight tool campaigns without benign false blocks. These guarantees cover only specified invariants on cooperative or proxy-fenced sinks; uncooperative external interfaces, operating-system refinement, and human delegation trials remain open.
