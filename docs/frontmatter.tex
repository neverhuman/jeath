\textbf{Abstract.}
What authority can remain after an agent is stopped or permission is withdrawn?
We separate admission revocation from sink-fenced revocation and implement a local
broker and cooperative tool service with distinct durable stores. Reservations
precede dispatch; ambiguous outcomes retain their charges. Under the stated sink
contract, effects after admission revocation are bounded by outstanding reserved
charges, while a durable fence acknowledgment excludes subsequent effects under
the withdrawn issuer epoch. A pinned Verus run verifies \VTwoProofs{} obligations
for the deterministic Rust policy core compiled into the broker; parsing,
storage, normalization, session identity, and the kernel remain trusted.
Independent trace checks, crash regressions, semantic positive controls, and
Landlock/seccomp probes exercise this boundary. Ten abstract mechanism omissions
and all 45 pairs have witnesses within a declared finite search language.
Scripted CPU comparisons and native AgentDojo/Progent integration controls are
reported separately from model experiments. All checked Linux GPUs were occupied;
the planned Qwen3 checkpoint comparison is unrun, so no empirical claim about
adversarial model utility or noninferiority is made. The result is a conditional
authorization and revocation artifact, not verification of an entire runtime or
an arbitrary external service.
