\textbf{Abstract.}\enspace
An AI system's capability to discover actions does not confer authority to execute
them, nor does stopping token generation revoke work already in flight. We separate
capability, aim, and conferred revocable authority, distinguishing broker admission
revocation from sink-fenced revocation across separate durable stores. Pre-dispatch
reservations conservatively bound ambiguous outcomes, attenuated sub-delegations bind
strengthened issuer requirements end-to-end, and durable epoch fences exclude
post-acknowledgment effects under withdrawn authority. A pinned Verus run verifies
\VTwoProofs{} SMT obligations for the Rust \texttt{policy-core} (\VTwoExecFns{}
executable predicates and \VTwoTheorems{} proof obligations over a specification
ledger model). Embedding this boundary in an explicit filtration model bounds
single-period catastrophic reach without assuming monitor independence, while
systematic negative controls expose where weaker assurances fail:
\VTwoAblationWitnesses/\VTwoAblationSets{} protocol omissions admit short
counterexamples, uncooperative non-idempotent sinks duplicate effects, six classifier
families stacked on a shared step exhibit strong residual failure dependence,
route-specific patching severs zero narrow-waist attack graphs, Good--Turing coverage
estimators miss strategic withholding, and steep rank tournaments select reckless
gambling even under conferred-benefit scoring. JSON framing, SQLite adapters, session
binding, and OS confinement remain trusted, and the predeclared
\VTwoComponentClaims-claim Qwen3 checkpoint study remains unrun
(\VTwoGpuSecondsUsed{} GPU-s).
