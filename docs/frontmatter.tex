\textbf{Abstract.}\enspace
Scaling an AI system's capability to search actions neither confers authority to execute
them nor makes endogenous safety classifiers invariant to optimization pressure: any
shared blindspot $J>0$ collapses with candidate search width $K_{\mathrm{opt}}$ as
$1-(1-J)^{K_{\mathrm{opt}}}\to 1$, while utility-uncertainty shutdown compliance
vanishes as preference certainty sharpens ($\sigma_H\to 0$). We decouple capability and
aim from \emph{conferred, revocable authority} enforced at exogenous capability-bearing
sinks via a total canonical wire bijection, Ed25519 quorum certificates, $d$-hop
attenuated Macaroons, and durable lease-fenced epoch floors. A pinned Verus run proves
\VTwoProofs{} SMT obligations across \VTwoExecFns{} executable functions and
\VTwoTheorems{} theorems in \texttt{policy-core} (rejecting all six soundness
mutations). Across a three-process cryptographic SQLite WAL cluster
(\VFiveClusterFuzzFrames{} adversarial wire frames, \VFiveClusterSubagents{} concurrent
subagents, \VFiveClusterSigkillCycles{} hard \texttt{SIGKILL} restarts, median commit
\VFiveClusterMedianUs\,$\mu$s) and \VFiveOptTotalExogEpisodes{} superintelligence
scaling episodes ($K_{\mathrm{opt}}\le \VFiveOptMaxWidth$), exogenous mediation records
$0$ decoder differentials, $0$ post-quorum leaks, and a \VFiveOptSlopePerDoubling{}
breach slope per search doubling. Over \VFiveStatGrandPairs{} paired CPU
\texttt{Qwen3-4B}/\texttt{8B} holdout and \texttt{AgentDojo v1.2.2} runs
(\VTwoGpuSecondsUsed{} GPU-s), complete mediation yields $0/\VFiveStatGrandPairs$
unauthorized commits versus $\VFiveStatGrandBaseLeaks/\VFiveStatGrandPairs$ unmediated
(exact Suissa--Shuster $p=\VFiveStatGrandSuissaSci$, anytime-valid Ville
$\log_{10}E=\VFiveStatVilleLogTenE$). Predeclared $N{=}\VFourHoldoutCasesPerCheckpoint$
Bonferroni bounds remain honestly inconclusive, and SQLite/OS formal refinement,
uncooperative external APIs, and frontier/human studies remain open.
