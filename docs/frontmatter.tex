\textbf{Abstract.}\enspace
An AI system's capability to discover actions does not confer authority to execute
them, nor does stopping token generation revoke work already in flight. We separate
capability, aim, and conferred revocable authority, distinguishing broker admission
revocation from sink-fenced revocation across separate durable stores. Pre-dispatch
reservations conservatively bound ambiguous outcomes, attenuated sub-delegations and
cryptographic tokens bind strengthened issuer requirements end-to-end, and durable
